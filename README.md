# اختبار الفرق بين التاء المربوطة والهاء

ملف اختبار تفاعلي باللغة العربية، جاهز للنشر على GitHub Pages.

## طريقة النشر السريعة

1. أنشئ مستودعًا جديدًا في GitHub.
2. ارفع ملف `index.html` إلى المستودع.
3. افتح Settings.
4. اختر Pages.
5. من Branch اختر `main`.
6. من Folder اختر `/root`.
7. اضغط Save.
8. بعد التفعيل سيظهر رابط الاختبار بصيغة:
   `https://USERNAME.github.io/REPOSITORY/`

## ملاحظة

الاختبار يعرض النتيجة مباشرة للطالب، لكنه لا يجمع النتائج في قاعدة بيانات.
